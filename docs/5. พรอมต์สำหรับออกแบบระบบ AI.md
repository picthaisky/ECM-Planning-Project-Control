### **บทนำการใช้งานแม่แบบ (How to Use)**

คัดลอกพรอมต์ด้านล่างนี้ และเปลี่ยนข้อความที่อยู่ในเครื่องหมายวงเล็บปีกกา {...} เพื่อควบคุมให้ AI สร้างซอร์สโค้ดและดีไซน์โครงสร้างของโมดูลในระบบ CM+ Project Control ได้อย่างมีแบบแผน ตรงตามสถาปัตยกรรมที่กำหนดไว้ 100%

โปรดช่วยสร้างซอร์สโค้ดและวิเคราะห์ออกแบบในหัวข้อโมดูลย่อยต่อไปนี้:

โดยข้อกำหนดด้านสถาปัตยกรรมทางเทคนิคที่คุณต้องปฏิบัติตามอย่างเคร่งครัดมีดังนี้:

1\. ส่วนหน้าบ้าน (Frontend Web Client):  
   \- เทคโนโลยี: React 19, TypeScript, Vite และ Tailwind CSS  
   \- รูปแบบ: Mobile-First, Progressive Web Application (PWA)  
   \- ธีมสี (UX/UI): เน้นความเป็นมืออาชีพ ล้ำสมัย และอบอุ่น (Professional, Futuristic, yet Warm)   
     \* ใช้โทนสีส้มอิฐ (\#E26D5C), สีส้มอมน้ำตาลไหม้ (\#A1523E), สีน้ำตาลเทาเข้ม (\#2B2523), และสีขาวงาช้างอุ่น (\#FDFBF7)  
     \* การจัดเรียงส่วนหน้าจอต้องสวยงาม ใช้งานสะดวกบนโทรศัพท์มือถือและแท็บเล็ตหน้างานก่อสร้าง  
   \- โครงสร้างไฟล์: แยกจัดวางตามสถาปัตยกรรมแบบ Module-Based (เช่น src/features/{module\_name})

2\. ส่วนหลังบ้าน (Backend Web API):  
   \- เทคโนโลยี: C\# .NET 10, Entity Framework Core 10, Web API (Controllers)  
   \- สถาปัตยกรรม: Clean Architecture \+ DDD แบ่งเลเยอร์ดังนี้:  
     \* Domain Layer: สร้าง Entities, Value Objects และกฎเกณฑ์ทางธุรกิจที่เกี่ยวข้อง  
     \* Application Layer: สร้าง CQRS (MediatR Commands/Queries), DTOs, และ Validator (FluentValidation)  
     \* Infrastructure Layer: สร้าง DbContext Configuration และ Fluent API mapping สำหรับ MSSQL Server  
     \* Presentation Layer: สร้าง Web API Controller ที่มี Security Filter และการระบุ Versioning

3\. ข้อกำหนดพิเศษเพิ่มเติม:  
   \- กรณีที่โมดูลเกี่ยวข้องกับการวิเคราะห์หรือสูตรคำนวณทางคณิตศาสตร์ (เช่น การแปลงค่าปริมาณน้ำฝนเป็นจำนวนวันหยุดทำงาน หรือสูตรคำนวณเงินงวดหักเงินค้ำประกัน): ให้แสดงสมการในรูปแบบ LaTeX เสมอ  
   \- เขียนโค้ดที่ทนทานต่อข้อผิดพลาด (Robust Code) มีกลไกการดักจับข้อผิดพลาด (Exception Handling) และสร้างชุดสอบย้อนกลับ (Audit Log) ทุกครั้งที่มีการแก้ไขข้อมูลในชั้นโดเมน
