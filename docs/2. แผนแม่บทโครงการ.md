# **แผนแม่บทโครงการ (Project Master Plan)**

## **โครงการพัฒนาซอฟต์แวร์ CM+ Project Control**

### **1\. วัตถุประสงค์และขอบเขตของโครงการ (Objectives & Scope)**

เป้าหมายคือการพัฒนาแพลตฟอร์ม CM+ Project Control ให้เป็นเว็บแอปพลิเคชันระดับองค์กรที่เสร็จสมบูรณ์ รองรับการทำงานทั้งบน Desktop และ Mobile (ผ่านเทคโนโลยี PWA) โดยยึดหลักเกณฑ์ความปลอดภัยของข้อมูล และโครงสร้างระบบสถาปัตยกรรมที่ยืดหยุ่นต่อการขยายตัว (Scalability)

#### **ขอบเขตของโครงการ (Project Scope):**

* **Phase 1: Foundation & Data Sync Engine:** พัฒนาโมดูลนำเข้า/ส่งออกข้อมูลไฟล์หลัก (.xlsx, .mpp, .xer) และโครงสร้างฐานข้อมูลความก้าวหน้า WBS  
* **Phase 2: Core Planning & Control Modules:** พัฒนา Gantt Chart Interactive, S-Curve Engine, Cash Flow forecasting และ Dashboard สรุปผล EVM  
* **Phase 3: Site Management Extensions:** พัฒนาโมดูลสนับสนุน ได้แก่ Photo Progress, Weather Log, Variation Order และ Payment Tracking  
* **Phase 4: Optimization, Mobile Integration & Security:** ปรับแต่ง PWA, พัฒนาระบบจัดเก็บไฟล์ภาพความละเอียดสูงบน Cloud Store และระบบสิทธิ์ผู้ใช้งาน (RBAC)

### **4\. แผนบริหารความเสี่ยง (Risk Management Plan)**

1. **ความเสี่ยงทางเทคนิค: ข้อจำกัดด้านประสิทธิภาพของเบราว์เซอร์เมื่อแสดงผล Gantt Chart ขนาดใหญ่**  
   * *ระดับผลกระทบ:* สูง (High)  
   * *แนวทางแก้ไข:* นำแนวคิด Virtualized List (เช่น react-window หรือ react-virtualized) มาใช้ในการวาดตาราง และคอมโพเนนต์ Gantt Chart เพื่อให้เบราว์เซอร์วาดผลเฉพาะแถวที่ปรากฏบนหน้าจอเท่านั้น รองรับข้อมูลได้มากกว่า 10,000 กิจกรรมโดยที่หน้าจอไม่กระตุก  
2. **ความเสี่ยงทางเทคนิค: ความถูกต้องแม่นยำของการคำนวณไฟล์ XER และ MPP**  
   * *ระดับผลกระทบ:* สูงมาก (Critical)  
   * *แนวทางแก้ไข:* ใช้ไลบรารีวิเคราะห์ที่เป็นมาตรฐานอุตสาหกรรมในส่วน Backend และสร้างชุดทดสอบความถูกต้อง (Automation Unit Test) เพื่อเปรียบเทียบผลลัพธ์การคำนวณระหว่าง CM+ กับ Primavera P6 แท้จริง ก่อนอนุมัติโค้ดขึ้นระบบใช้งานจริง  
3. **ความเสี่ยงด้านการใช้งานหน้างาน: การเชื่อมต่ออินเทอร์เน็ตล้มเหลวขณะอัปโหลดรูปภาพความก้าวหน้า**  
   * *ระดับผลกระทบ:* ปานกลาง (Medium)  
   * *แนวทางแก้ไข:* พัฒนาระบบฝากไฟล์ใน Client Local Storage (IndexedDB) บนเว็บเบราว์เซอร์ เพื่อเก็บไฟล์รูปภาพที่ผ่านการบีบอัดแล้วชั่วคราว เมื่อระบบตรวจพบว่ากลับมาเชื่อมต่อเครือข่ายได้อีกครั้ง จะอัปโหลดข้อมูลเข้า Cloud Server โดยอัตโนมัติ (Background Sync)
