### **2\. บทบาท หน้าที่ และทักษะเฉพาะด้านของแต่ละเอเจนต์ (Agent Roles & Competencies)**

#### **A. Product Owner Agent (PO-AI)**

* **หน้าที่หลัก:** รับโจทย์ทางธุรกิจ แปลงความต้องการเป็น User Stories บันทึกจัดลำดับความสำคัญของงานย่อยใน Product Backlog และตรวจสอบผลลัพธ์ของฟีเจอร์ต่างๆ ให้ตรงตามหลักวิชาชีพวิศวกรรมก่อสร้าง  
* **ทักษะเด่น:** การวิเคราะห์ระบบบริหารงานก่อสร้าง, กฎระเบียบและมาตรฐานการประเมินราคา, ดัชนีตัวชี้วัด Earned Value Management (EVM)

#### **B. System Architect Agent (SA-AI)**

* **หน้าที่หลัก:** ออกแบบโครงสร้างซอฟต์แวร์ ควบคุมให้เกิดการแยกสิทธิ์ตามเลเยอร์ Clean Architecture และนิยามโครงสร้างตารางข้อมูลใน MSSQL ให้มีประสิทธิภาพสูงสุด  
* **ทักษะเด่น:** Domain-Driven Design (DDD), ER Diagram Design, การออกแบบความปลอดภัย API (OAuth2/JWT), การวางขีดความสามารถการรองรับปริมาณงานจำนวนมาก (Scalability Design)

#### **C. Backend Developer Agent (BE-AI)**

* **หน้าที่หลัก:** เขียนโค้ดฝั่ง Server-side ทั้งหมด พัฒนาอัลกอริทึมคำนวณ Critical Path, ตัวดึงข้อมูลสกัดโครงสร้างไฟล์ MPP และ XER, บริการจัดการระบบไฟล์ความละเอียดสูง และ APIs ของระบบ  
* **ทักษะเด่น:** C\# .NET 10, Entity Framework Core 10, Web API Controllers, ไลบรารีถอดรหัส XML/Binary (.NET MPXJ), การเขียน SQL Query ปรับแต่งความเร็ว (Performance Tuning)

#### **D. Frontend Developer Agent (FE-AI)**

* **หน้าที่หลัก:** พัฒนาส่วนหน้าตาและโปรแกรมรับส่งข้อมูลของผู้ใช้งาน รองรับสถาปัตยกรรมแบบ Single Page Application (SPA) และ Progressive Web App (PWA) ให้ทำงานได้อย่างลื่นไหล รวดเร็ว  
* **ทักษะเด่น:** React 19 (Hooks, Context, Web Worker), TypeScript, Vite, CSS Tailwind, การตกแต่งระบบธีมสีส้ม-น้ำตาลอุ่น, การจัดการเก็บข้อมูลภายในเบราว์เซอร์ (IndexedDB, Service Worker)

#### **E. QA & DevOps Agent (QA-AI)**

* **หน้าที่หลัก:** จัดทำระบบตรวจสอบความปลอดภัยและความถูกต้องอัตโนมัติ (Integration & Unit Testing) ดูแลการจัดการอัปเดตระบบอัตโนมัติ (CI/CD Pipelines) และการเตรียมพร้อมระบบเซิร์ฟเวอร์แบบ Docker Container  
* **ทักษะเด่น:** xUnit Testing, Playwright/Cypress สำหรับการจำลองกดหน้าจอ UI, GitHub Actions/GitLab CI, Docker, สถาปัตยกรรมคลาวด์พื้นฐาน (AWS / Azure)

### **3\. แนวทางการทำงานร่วมกันระหว่างมนุษย์และเอเจนต์ (Human-AI Collaboration Guidelines)**

เพื่อให้เกิดประสิทธิผลสูงสุด ทีมงานที่เป็นมนุษย์จะเป็นผู้ดูแลในฐานะ "ผู้อนุมัติขั้นสุดท้าย (Human-in-the-loop)" โดยมีแนวทางปฏิบัติที่ชัดเจนดังนี้:

1. **การยืนยันการออกแบบ (Design Review):** สถาปนิกและนักวิเคราะห์ระบบที่เป็นมนุษย์จะเป็นผู้ตรวจทานความถูกต้องของ Database Schema และสถาปัตยกรรมที่ออกแบบโดย SA-AI ก่อนที่ PO-AI จะนำไปส่งงานให้ BE-AI และ FE-AI ลงมือเขียนโค้ด  
2. **การตรวจทานรหัสโค้ด (Pull Request Code Review):** โค้ดทั้งหมดที่สร้างจาก BE-AI และ FE-AI จะต้องผ่านการรันประเมินความปลอดภัยโดยอัตโนมัติ และได้รับความเห็นชอบอย่างน้อย 1 เสียงจากวิศวกรซอฟต์แวร์อาวุโสที่เป็นมนุษย์ก่อนรวมเข้าสู่แกนระบบหลัก  
3. **การทดสอบจริงหน้างาน (User Acceptance Testing):** หน้าจอใช้งานบนสมาร์ทโฟนของระบบ Photo Progress และ Daily Weather Log ที่สร้างขึ้นใหม่ จะต้องส่งไปทดสอบจริงกับวิศวกรควบคุมงานและผู้รับเหมาที่อยู่ ณ ไซต์งานก่อสร้างเพื่อรับฟีดแบ็กจริงมาปรับแต่งความเสถียรของแอปพลิเคชัน
